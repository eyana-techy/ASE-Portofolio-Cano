# Agentic Software Engineering


## Course Introduction

This portfolio showcases my activities, reflections, and outputs throughout the course Agentic Software Engineering. The course focuses on how AI agents work, how they make decisions, use tools, and carry out tasks with minimal human intervention. It also introduces software development practices such as Agile methodology, version control, collaboration, testing, and responsible use of AI.

As I go through this course, I hope to gain a better understanding of how AI agents are used in software development and how they can help make tasks more efficient. I also want to learn how to use these technologies properly while being aware of their limitations, possible risks, and ethical considerations.

## Personal Learning Goals

- Gain a better understanding of Agentic Software Engineering and how intelligent agents work.
- Identify the differences between AI agents and traditional software applications.
- Improve my skills in using Git and GitHub for managing code and collaborating on projects.
- Learn how Agile practices can be used in developing AI-based software.
- Understand the possible risks, security concerns, and ethical issues of using AI agents.
- Develop responsible AI usage habits while recognizing the importance of human supervision.

## Reflection from Part A

Through the Concept Analysis activity, I learned that AI agents are more advanced than traditional applications because they can understand objectives, plan their actions, and complete tasks through a series of steps. However, these capabilities also come with possible challenges, such as incorrect results, security risks, and actions that may not be intended. This made me realize that creating AI-powered systems requires more than just making them functional. They should also be dependable, safe, and designed for responsible use. Even with the capabilities of AI, human involvement is still necessary to review its outputs, guide its decisions, and ensure that it is being used appropriately.
